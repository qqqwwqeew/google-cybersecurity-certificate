# Botium Toys Security Audit

A simulated security audit and risk assessment completed as part of the Google Cybersecurity Certificate.

## Objective

Assess the organization's security posture, identify risks and control gaps, and document security recommendations.

## Assessment Areas

The project covers:

- audit scope and goals
- risk assessment
- security controls
- compliance considerations
- recommended improvements

## Deliverables

- Botium-Toys-Scope-goals-and-risk-assessment-report.pdf
- Controls-and-compliance-checklist.pdf

## Skills Demonstrated

- Security risk assessment
- Security controls
- Compliance analysis
- Audit documentation
- Security recommendations

## Project Context

This is a simulated educational assessment, not a production security audit.
