# Data Leak Analysis Worksheet

This folder contains a completed worksheet for the Google Cybersecurity Certificate covering a data leak scenario and the principle of least privilege.

## Summary

- Identifies access-management mistakes that contributed to the leak.
- Reviews NIST SP 800-53 control AC-6: Least Privilege.
- Recommends limiting shared access to task-required files and regularly reviewing permissions.
- Explains how these controls reduce unauthorized disclosure risk.

See [`data-leak-analysis-worksheet.pdf`](./data-leak-analysis-worksheet.pdf) for the completed worksheet.
