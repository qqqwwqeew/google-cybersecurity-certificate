# OSINT Investigation

A simulated investigation completed as part of the Google Cybersecurity Certificate.

## Objective

Analyze information relevant to an incident scenario using open-source intelligence (OSINT) techniques and document the findings.

## Deliverable

- Incident report analysis.pdf

## Skills Demonstrated

- OSINT research
- Information analysis
- Incident documentation
- Evidence-based investigation

## Project Context

This is an educational simulated investigation. Sources and conclusions should be interpreted within the provided scenario.
